# 낙낙 취미 시작 지도

고른 취미를 한국체육산업개발(KSPO)의 무료 강습 영상, 스포츠센터 강좌, 우리 동네 공공 강좌, 올림픽공원으로 이어 주는 웹 페이지입니다.
「2026년도 공공데이터 활용 경진대회」(한국체육산업개발) 출품작입니다.

- 사용 데이터: 공공데이터포털(data.go.kr) 한국체육산업개발 개방 데이터 12종(파일 10종, 오픈 API 2종), 전국평생학습강좌표준데이터, 한국문화정보원 전국 문화 여가 활동 시설(클래스)
- 로그인과 개인정보 수집이 없습니다. 강좌 신청과 결제는 각 기관 페이지에서 합니다.
- 주소 끝에 `?h=취미아이디&r=지역`을 붙이면 그 결과가 바로 열립니다. 예: `?h=swimming&r=서울`
